# 数学乐园（math6q）

青岛版六三制（1-6 年级 12 册）小学数学练习 Web 应用，部署在飞牛 NAS（fnOS）的 Docker 环境中。

> ⚠️ **安全说明**：本仓库代码已脱敏，所有真实凭证、内网地址、用户数据均以占位符替代或排除。请勿将真实密钥提交至此仓库。

## 功能模块

- **练习与判分**：按课本单元出题，AI 判分 + 错题库 + 知识点点亮
- **云端同步**：多设备登录同一账号，学习进度集中存 NAS（乐观锁 + 原子写 + 双备份）
- **学习报告**：本人时段报告 + 管理员全账号报告
- **报告数据同步镜像（v4.0）**：所有账号报告在新增/更新后即时同步到持久化镜像，含一致性校验与对账

## 架构

```
浏览器 ──nginx:8766──► 静态页面 + /api 反代 ──► shuxue-api:8877 (Node)
                              │                        │
                              └─/ai 反代─► AI 网关      └─ data/（存档/会话/报告镜像）
```

- 管理员报告镜像：`data/reports/mirror.json`，每账号唯一键，写入即同步
- 一致性校验接口：`/api/admin/report/mirror/verify`（检出遗漏/陈旧/损坏/孤儿/失败）
- 手动对账：`POST /api/admin/report/mirror/rebuild`
